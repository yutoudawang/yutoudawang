## Performance Resources

This repository includes resources to help identify and improve slow or inefficient code:

- **[CODE_EFFICIENCY_GUIDE.md](CODE_EFFICIENCY_GUIDE.md)** - Comprehensive guide covering:
  - Common performance issues and how to fix them
  - Profiling tools for different languages
  - Optimization techniques and best practices
  - Language-specific performance tips
  
- **[performance_examples.py](performance_examples.py)** - Runnable Python examples demonstrating:
  - Algorithm complexity (O(n²) vs O(n))
  - String concatenation performance
  - Caching and memoization
  - Data structure selection
  - Memory efficiency techniques

Run the examples:
```bash
python3 performance_examples.py
```
